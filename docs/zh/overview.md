# TurboPhysAI 概述

## 产品定位

TurboPhysAI 是面向 Physical AI 领域模型的训练性能优化组件，覆盖自动驾驶、具身智能和世界模型等方向。组件在不修改模型源码的前提下，提供从公共算子、框架热点到模型计算图、数据链路和训练过程的分层优化能力，提升模型在 HCU 上的训练效率。

对于已支持的模型，TurboPhysAI 提供与接入基线匹配的模型专用优化；其他模型可使用与当前软件环境和目标入口匹配的公共优化。

## 适用场景

| 应用场景 | 面临的问题 | TurboPhysAI 的作用 |
| --- | --- | --- |
| 多个模型存在相同计算热点 | 相同算子和框架热点需要重复优化和验证 | 提供可跨模型复用的公共优化 |
| 模型存在端到端性能瓶颈 | 瓶颈分布在算子、计算图、数据链路和训练过程 | 对完整训练链路进行组合优化 |
| 模型版本持续演进 | 优化代码直接混入模型源码，升级和维护成本较高 | 保持优化实现与模型源码分离 |

## 提供的能力

TurboPhysAI 提供四类能力：

- **公共性能优化**：提供可跨模型复用的 HCU 高性能算子和框架优化；
- **模型专用优化**：针对具体模型的计算图、数据链路、编译热点和训练过程进行组合优化；
- **兼容适配**：处理优化应用所需的导入路径、符号名称和注册方式差异；
- **优化应用与结果记录**：统一应用模型优化并启动原训练命令，记录各项优化的应用状态，便于确认优化是否生效并回溯问题。

## 使用流程

一次完整使用包括：

1. 按模型官方说明准备仓库、数据集、权重和可运行的训练环境；
2. 安装与当前 HCU 软件环境匹配的 TurboPhysAI；
3. 在原训练命令前使用 `turbo-physai run` 启用对应模型的优化；
4. 查看优化应用报告，并完成模型精度和性能验证。

开始使用请阅读[安装指南](get_started/installation.md)和[快速开始](get_started/quick_start.md)。当前支持范围见[模型支持清单](models/support_list.md)。
